# Nivalis Nights Wiki feedback

This public repository receives player-submitted game data and corrections for [Nivalis Nights Wiki](https://nivalisnightswiki.net/).

Submissions are public research leads, not automatically published facts. Each report is reviewed against its evidence, game version, and the wiki's [editorial policy](https://nivalisnightswiki.net/editorial-policy/) before it can affect a page.

## Before submitting

- Use the structured Issue forms rather than a blank issue.
- Include the game version or build, platform, language, and observation context.
- Link only to evidence you have permission to share.
- Do not include personal information, save files, account credentials, copied guide text, or third-party images uploaded without permission.
- One specific fact or one closely related group of facts per submission is easiest to verify.

[Open a submission or correction](https://github.com/Dadong007/nivalis-nights-wiki-feedback/issues/new/choose)
